# Add Lock Files and Security Scanning to Package

## Task Brief
Integrate requirements.txt or poetry.lock into your package repo; add dependency security scanning and document vulnerability remediation.

## Scenario
Your team requires reproducible builds and security compliance. Add lock files and automated vulnerability scanning to the package.

## Deliverables
- Lock file (requirements.txt or poetry.lock)
- Security scanning workflow configured

## Success Criteria
- Lock file pins all direct and transitive dependencies
- Security scan runs on pull requests
