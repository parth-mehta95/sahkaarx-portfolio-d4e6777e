# Integrate Security Scanning into CI/CD Pipeline

## Task Brief
Add vulnerability scanning tools to your package repo; resolve identified CVEs and document remediation in your CI/CD workflow.

## Scenario
Your team requires automated security scanning in CI/CD to catch vulnerabilities before PyPI publication.

## Deliverables
- GitHub Actions workflow with security scanning
- Vulnerability report with remediation steps
- Updated lock file with patched dependencies

## Success Criteria
- Scanning tool runs on every commit
- All critical CVEs resolved
- Workflow passes with clean report
