# Establish CI/CD Pipeline with PR Automation

## Task Brief
Build automated testing and linting checks triggered by pull requests to validate package quality.

## Scenario
Your team needs automated quality gates on PRs. Add GitHub Actions workflows for testing, linting, and code coverage to the package repo.

## Deliverables
- GitHub Actions workflow file
- .github/workflows directory configured

## Success Criteria
- Workflow runs on every PR
- Tests and linting execute automatically
