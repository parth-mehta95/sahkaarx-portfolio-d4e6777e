# Create and Review Pull Requests

## Task Brief
Create pull requests with templates, implement branch protection rules, and practice code review cycles on your package repo.

## Scenario
Your team requires PR templates and branch protection. Set up PR workflow with code review requirements and merge safeguards.

## Deliverables
- PR template file
- Branch protection rules configured

## Success Criteria
- PR template enforces description and checklist
- Main branch requires reviews before merge
